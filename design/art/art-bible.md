## 1. 视觉身份宣言 (Visual Identity Statement)

### 一句话视觉铁律

> "钟塔内的一切画面都是'冷静的舞台'；只有完美弹反成功后的那一拍，才允许全片预算级的光色、粒子与构图同时'爆灯'。"

任何新增资产、Shader、贴图尺寸、UI 动效，若不能同时服务于「常态可读」与「弹反峰值可感知」，默认砍掉或降级——把性能与注意力留给弹反与连锁反击的视听高潮。

### 支撑原则

#### 原则 1：弹反即银幕峰值 (Parry as the Peak Beat)

将"完美弹反 → 团队反击"视为单场战斗里唯一的视觉高潮节拍，其余动作保持清晰、利落、不抢戏。

*Design test*: 当纠结"要不要给这个技能/普攻也加同等规模的 bloom、全屏闪、强色相偏移"时，选择**否**——把同等量级的对比度、饱和度跃迁与屏幕边缘光 reserved 给完美弹反及其触发的反击链。

*服务支柱*: 精准即快感 (Precision is Pleasure) + 层层递进 (Escalating Mastery)

#### 原则 2：经济密度 (Economical Density)

在严格低多边形、小纹理与有限 draw call 下，用手绘低多边形 + 受控的 2.5D 纵深 + 少而准的材质变化堆出"小而精"的密度，而不是用资产数量或贴图分辨率堆体量。

*Design test*: 当纠结"该加更多小道具/更碎的法线细节，还是该合并 mesh、拉大色块与剪影可读性"时，选择**合并与剪影优先**——宁可减少物体种类与贴图张数，也要保证纵深可读、威胁提示可读、以及为弹反峰值预留 GPU/CPU 余量。

*服务支柱*: 小而精致 (Small but Exquisite)

#### 原则 3：人物锚定情感 (Characters Anchor the Heart)

钟塔环境走冷色、工业哥特与机械节律；玩家情感与叙事重量主要由角色立绘/肖像与关键表情帧承担，环境负责氛围与垂直推进感，不与人争视线。

*Design test*: 当"叙事重头戏发生在 UI 立绘与 3D 场景之间，预算只能深做一边"时，选择**深做角色肖像与对话态的情绪光色**（GNOSIA 式辨识度），场景保持风格统一下的模块化可读块面。

*服务支柱*: 角色即动力 (Characters Drive the Journey)

## 2. 氛围与光照 (Mood & Atmosphere)

每种游戏状态都有独特的视觉性格。核心节奏：**冷静舞台（常态）↔ 暖色爆灯（仅完美弹反）**。

### 2.1 箱庭探索 (Exploration)

- **情绪**：好奇与疏离并存——废弃剧场里翻道具的兴奋
- **光照**：冷底 5200–6500K；窄束暖光（钨丝 2700–3200K）只打可交互物与叙事残片。顶侧光 + 齿轮缝隙漏下的斜向硬边光
- **氛围**：寂静、锈蚀、可阅读、略带诗意
- **能量**：低–中（稳定、可呼吸）
- **关键视觉**：剪影优先的环境可读性——拱门、悬梯、大齿轮的负形；手绘低多边形上的节制笔触纹理（锈、尘、潮）
- **过渡**：→ 战斗：环境动态收敛，风/尘粒子减档，镜头切平构图；← 战后：半拍环境声+雾浓度回升，重新"拉大"空间

### 2.2 指令阶段 (Command Phase)

- **情绪**：冷静推演——棋手在后台对谱的紧张
- **光照**：场景冷中性，菜单高光偏青灰银。UI 自带微弱自发光边缘，场景本体对比略压
- **氛围**：克制、清晰、手术刀式、金属冷感
- **能量**：中（脑力负荷上升，画面仍"省电"）
- **关键视觉**：层级分明的 UI 光——选中技能的窄高亮描边 + 敌人威胁范围的冷色提示覆盖；角色头像保持 GNOSIA 式手绘温度但面积小
- **过渡**：← 探索：UI 滑入时极短景深收束；→ 弹反：裁切画幅或轻微推轨向攻击源，预警线开始提高频闪权重

### 2.3 弹反阶段 (Parry Phase)

- **情绪**：高压专注——聚光灯收窄到一根钢丝
- **光照**：冷底 + 极高指向性窄光源（追光），把攻击轨迹从环境里"抠"出来。逆光或侧逆光强化剪影与攻击轮廓
- **氛围**：锋利、窒息、节拍化、工业精密、舞台收束
- **能量**：高（持续张力，仍是"冷舞台"预算）
- **关键视觉**：可读的攻击几何 + 节拍化 UI。背景齿轮/摆锤变成模糊运动纹理，前景只留判定点、预警环、刀光剪影。粒子以金属屑/火花屑少量点题
- **过渡**：← 指令：追光聚焦 + 低频嗡鸣；→ 成功：判定前一帧压暗1-2帧蓄力；→ 失败：追光散开

### 2.4 完美弹反高潮 (Perfect Parry Climax)

- **情绪**：释放与凯旋——全片唯一"观众席灯全亮"的峰值，炽烈但短暂
- **光照**：**冷暖对撞**——环境保留冷底，反击主体/刀光拖尾允许饱和暖色与霓虹位移（Sayonara Wild Hearts 式强度跟随）。全片最高对比 + 允许局部过曝。正面舞台光短暂接管
- **氛围**：爆裂、华丽、仪式化、转瞬即逝、团队合一
- **能量**：**峰值**（光、色、粒子、构图同时上场）
- **关键视觉**：团队反击的"合奏剪影"——一人主刀光，其余人互补几何补位；粒子用玻璃尘/金粉/电弧但有清晰主形状
- **过渡**：← 弹反蓄力帧后爆灯；→ 回常态：高光在 0.3–0.8s 内收回冷灰，霓虹像断电般收束

### 2.5 弹反失败 (Failure / Damage)

- **情绪**：挫败但不羞辱——痛感清晰，让玩家想立刻找回下一拍
- **光照**：短促偏暖"痛觉闪"（橙红 1–2 帧）立刻被冷灰雾拉回。追光"碎裂"，改为不安定的顶光/底光
- **氛围**：刺痛、失衡、短暂、工业冷回潮
- **能量**：中高（短 burst）→ 迅速降到中低
- **关键视觉**：受击轮廓断裂 + UI 红色信息条；一帧齿轮错位阴影（工业恐怖的一点点暗示）
- **过渡**：→ 指令：回到冷 UI 覆盖时半拍灰阶上升，表示"重拿控制权"

### 2.6 休息与对话 (Rest & Dialogue)

- **情绪**：亲密与安放——工业废墟里唯一稳定的"人心温度"
- **光照**：肖像暖光 3200–4000K 集中在脸部与手部；背景维持冷蓝灰。45°柔光为主，小蜡烛/油灯作点光源
- **氛围**：私密、柔软、可信、略带疲惫、留白
- **能量**：低–中（情绪深但不躁）
- **关键视觉**：手绘立绘的笔触与微表情 + 极简场景（工业远景虚化成大色块）；道具茶杯、绷带、齿轮挂件做情感锚点
- **过渡**：← 战后：镜头减速+景深变浅，色温逐步爬升；→ 再战：肖像光收一档，冷雾回涌

### 2.7 Boss 战 (Boss Encounter)

- **情绪**：逐级攀登的压迫与精通感——强度升级但仍遵守弹反爆灯规则
- **光照**：冷底逐段加入更窄更硬的结构性高光（金属刃口、巨型摆锤边缘）；阶段转换用色温偏移 200–400K 微调，不一次拉满
- **氛围**：史诗感、精密机械、窒息递进、仪式化压迫、可学习的危险
- **能量**：中→高→峰值仅在玩家打出的完美弹反上
- **关键视觉**：分相舞台装置——每阶段改变"舞台几何主形状"（摆锤半径、齿轮转速剪影、破碎地板负形）
- **过渡**：← 探索接近 Boss 门：环境叙事密度上升（锈痕、抓痕、停摆的钟）；→ 战后：比小怪战更长的"余震衰减"

### 总节奏约束

> 七种状态里，**只有「完美弹反高潮」允许冷暖对撞 + 过曝霓虹 + 全粒子构图同帧峰值**；其余状态用冷舞台、剪影、局部追光/UI 冷高光制造差异。

## 3. 形状语言 (Shape Language)

### 3.1 角色剪影哲学

**手机可读性规则**：在 64–96px 等效高度仍能 3 秒内区分阵营、职能大类、威胁距离。剪影靠外轮廓 3 个锚点（头冠/发型、肩腰比、武器/道具的"伸出去的一块"），避免细碎飘带。

**三名可玩角色形签名**：

| 角色轴 | 形签名 | 情绪读取 |
|---|---|---|
| **A：秩序/节拍** | 竖向矩形 + 短横向（披风/背板形成稳定门形），武器贴近身体中线 | 可靠、克制、像节拍器 |
| **B：机动/锋刃** | 斜三角 + 外伸的尖（单侧长武器/硬边布），剪影明显前倾 | 锋利、抢先手、紧张 |
| **C：技艺/仪式** | 圆环/弧 + 悬挂件（齿轮饰、摆锤坠），外轮廓更闭合 | 神秘但理性，精密仪器 |

**敌人原型剪影法则**：

| 类型 | 主形 | 读取 |
|---|---|---|
| **快攻 (Fast)** | 楔形/镖形/拉长平行四边形，肩窄四肢前探 | "一条线扎过来" |
| **重击 (Heavy)** | 倒梯形/立方体堆叠，宽肩下沉重心 | "一堵墙压过来" |
| **施法 (Caster)** | 钟摆形/沙漏暗示，上半身"满"（蓄能感） | "一个正在充能的圆" |

**Boss 剪影**："塔"或"钟"的母题外轮廓，上重下稳或巨大圆+单轴。身上 2–3 个可攻击窗口用形缺口（凹进去的负空间）提示。阶段推进改变主轮廓的一个角。

### 3.2 环境几何

**主导**：硬边机械 + 哥特建筑 = 角与弧的"对位"。
- **角**（齿轮齿、桁架、扶壁、阶梯）→ 秩序、危险边缘、可站位
- **弧**（拱门、玫瑰窗、大轮缘、摆锤轨迹）→ 时间、命运感、可预测节律
- **有机从属**：苔藓、裂痕、布幔只作"破角的小柔软"，面积小、低频出现

**钟塔三母题**：
1. **圆 (Clock)**：窗、轮、平台外沿 → 循环与倒计时
2. **齿 (Gear)**：重复放射短边 → 系统与压迫
3. **竖轴 (Pendulum)**：垂线、拉索、井式中庭 → 坠落感与重心

**层间视觉区分**（同一套模块化资产，靠配比变化）：
- **低层**：窄竖井 + 密齿轮背景 → 窒息、初学
- **中层**：宽辐条 + 大圆窗负空间 → 喘息、策略感
- **高层**：大弧与单轴摆锤主导 → 终局舞台感

### 3.3 UI 形体语法

**双层语言**：
- **结构层**（框、分区、进度）：独立 HUD 语言——圆角矩形 + 细线刻度，触控与可读性优先
- **装饰层**（纹章、选中态）：轻量齿轮/刻度纹——像舞台字幕条上的暗花，不抢战斗读条

**几何家族**：
- 按钮：胶囊 + 1px 内描边；主 CTA 可轻微非对称斜切
- 菜单面板：大圆角矩形，分区用细竖线刻度
- 生命/资源条：扁六边形或分段矩形（齿距感），段间硬断开
- 禁用/危险态：圆角半径减小→几何"变冷"传达风险

### 3.4 弹反时刻的形变

仅在成功弹反帧附近（约 0.15–0.35s 窗口）允许全预算级形语言：
- **放射短硬线 + 断开的圆环碎片**（表盘炸裂一帧又收回），沿摄像机平面展开
- 粒子跟"圆/齿"母题走，避免随机 blob
- 构图短暂中心对称或强透视向心线
- 结束后形语言立刻回落：放射线衰减、圆环碎段收回细刻度、粒子密度断崖下降

> **形体一句话**：日常用哥特机械的角与弧搭成冷静舞台；角色与威胁用三种剪影语法说话；环境用母题配比推进楼层；UI 像怀表般克制；唯有完美弹反瞬间，才允许圆齿形在构图上短暂崩解再合拢。

## 4. 色彩系统 (Color System)

### 4.1 主色板（7 色 + 语义）

| 色名 | Hex | 在世界里的含义 |
|---|---|---|
| **钟塔深蓝** | `#1A2338` | 砖石、承重结构，"时间被锁住"的底色 |
| **灰紫雾** | `#3D3A52` | 远景、雾体积、不可达层——被遗忘的楼层与叙事留白 |
| **钢青灰** | `#5C6675` | 齿轮、导轨、铆钉——可读的中性工业材质 |
| **幽蓝高光** | `#4A7C9E` | 非威胁的系统级神秘：存档点弱光、弱引导、环境叙事微光 |
| **霜白刃反** | `#D8E4EC` | UI 细线、刀轨、弹反窗口边缘——高可读冷白 |
| **琥珀金** | `#C9A227` | 肖像辅光、关键道具、成功与奖励——与冷底形成"唯一允许的暖" |
| **熔橙** | `#E85D2C` | 威胁预警、失败闪帧、Boss 通电阶段——完美弹反爆灯的冷暖对撞色 |

可选节拍色（仅完美弹反一帧）：**霓虹品红 `#FF2E88`** — 与金/橙对撞，"规则被短暂打破"；平时禁用。

### 4.2 语义色用法

| 语义 | 主色 | 用法 |
|---|---|---|
| **危险/威胁** | `#E85D2C` 熔橙 | 攻击预警轨迹、失败闪帧（1-2帧），辅 `#8B2E1F` 做描边暗部 |
| **安全/疗愈** | `#D8E4EC` + `#4A7C9E` 弱渐变 | 不用大面积鲜绿（与工业哥特冲突），安全区 = 呼吸感变亮、对比略降 |
| **奖励/成功** | `#C9A227` 琥珀金 | 唯一主奖励锚色，拾取/结算叠浅金 `#E8D48A` 高光条 |
| **叙事/发现** | `#524E6A` + `#4A7C9E` 点光 | 灰紫提亮一档 + 幽蓝点光，冷系里"略亮、略蓝" |
| **UI 中性** | `#5C6675` 底 / `#8FA3B0` 次文字 / `#D8E4EC` 主文字 | 信息强调用 `#6BA3B8` 小面积描边 |

### 4.3 分层色温规则

| 楼层 | 等效色温 | 色相/明度倾向 | 感受 |
|---|---|---|---|
| **1层（门厅/传动底层）** | ~5800K 青灰 | 多 `#5C6675`，雾少，阴影略蓝绿 `#2A3548` | 压抑但清晰，建立工业可读性 |
| **2层（齿轮中庭）** | ~5500K 灰紫 | 雾 `#3D3A52` 加重 5-10%，中灰 `#4A4658` 填隙 | 空间变"厚"，探索感加强 |
| **3层（钟绳/观测廊）** | ~5200K 蓝主导 | 天空灌入 `#2D3F5C` 冷蓝光束 | 垂直感、仪式感，为 Boss 铺垫 |
| **4层（Boss/核心机芯）** | ~5000K 最低温 | 基底 `#1A2338`，Boss 阶段逐级 + 熔橙描边 10%→40% | "结构在苏醒"而非"世界变暖" |

### 4.4 UI 色板

| 用途 | Hex | 与世界色分歧 |
|---|---|---|
| 面板深底 | `#222831` | 比世界底色更中性偏黑，减少与场景雾竞争 |
| 面板次级底 | `#2E3540` | 略抬明度，保证小屏可读 |
| 主文字/图标 | `#D8E4EC` | 与世界霜白一致，品牌连续 |
| 次级文字 | `#8FA3B0` | 比场景钢灰更偏 cyan-silver |
| 选中/焦点 | `#6BA3B8` | 不用场景幽蓝 `#4A7C9E`，避免混淆 |
| 正向反馈 | `#C9A227` | 与世界奖励金同源 |
| 危险/取消 | `#E85D2C` | 与世界威胁同源，UI 内面积控制在条/边 |

### 4.5 弹反反馈色序列

1. **常态**：环境 `#1A2338`~`#3D3A52`，无额外 Bloom
2. **弹反窗口开启**：刀轨/框体霜白 `#D8E4EC` 提亮 8-15%，背景整体压暗 5-8%（明度为主，色相不动）
3. **普通弹反成功**：短促 <200ms 刃反闪白 + 环境 +5% 明度回弹，不出现大面积金/橙
4. **完美弹反**：第1帧聚光核心 `#C9A227`→`#E8D48A` 径向金光；第2帧边缘叠熔橙 `#E85D2C` + 霓虹品红 `#FF2E88` 细边；允许轻微过曝（贴图 emissive + 屏幕 Add，单 Pass）
5. **余韵**：0.3-0.6s 拉回冷底 + 灰紫雾浓度 +10-20%；失败分支 1-2帧 `#E85D2C` 全屏闪→冷雾 Pullback

### 4.6 色盲安全

| 语义配对 | 风险 | 备份手段 |
|---|---|---|
| 奖励金 vs 威胁橙 | 低亮屏上金橙皆偏黄 | 奖励：六角星/勾 + 上行音效；威胁：锯齿框 + 低频脉冲 |
| 弹反窗口 vs 环境高光 | 皆偏亮冷 | 窗口：固定几何框 + 节奏性滴答；环境无节奏 |
| 可交互 vs 装饰金属 | 同钢灰族 | 可交互：窄暖边 1px + 浮动图标；装饰无图标 |
| UI 焦点 vs 禁用 | 明度接近 | 焦点：2px 虚线动效 + 轻微缩放；禁用：斜线纹理覆盖 |

## 5. 角色设计方向 (Character Design Direction)

### 5.1 三人组视觉定位

三人共享同一套"舞台语法"——低饱和环境色、金属与石材的冷灰、钟表齿轮的重复节奏。服装剪裁偏克制、直线多、装饰少。对比手段靠**剪影层级**，不靠花纹堆砌。

并排时轮廓形成高中低或前中后层次——B 明显前倾最靠前，A 最正，C 略收。小屏一眼分出"稳/冲/仪"三种气质。

### 5.2 辨识度规则（敌我友一眼区分）

**优先级**：剪影 > 体态动画 > accent 色标 > 面部

1. **剪影**：敌方楔/倒梯/钟与友方 A/B/C 三类严格不混淆
2. **阵营色**：极小的高识别符号块（护肩内侧条、腰带扣、袖口环），面积小，符合舞台冷静
3. **头部识别**：头盔轮廓/发型外轮廓/肩宽比例三选一必须有极强记忆点
4. **动画语言**：快敌高频小位移 / 重敌低重心下沉 / 法敌中轴稳定手势强

### 5.3 表情与姿态档位

| 场景 | 姿态 | 表情 |
|---|---|---|
| **战斗（3D）** | 略舞台化：关键帧清晰、停顿感强 | 中低夸张：眉/眼神/嘴角 1-2 个清晰信号 |
| **对话（立绘）** | 强调肩线、头颈角度的叙事 | 中高表现力：GNOSIA 式"一句话一个态度" |
| **完美弹反** | 允许单帧 pose 略夸张（保持剪影可读） | 短暂拉满表情/眼神光 |

**一句话**：3D 是"冷静舞台上的演员"；立绘是"靠近观众席的面部特写"。

### 5.4 立绘与 3D 双载体关系

**必须一致**：剪影几何（A/B/C 归属）、accent 色位置与占比、1 个标志性符号、材质叙事语言

**刻意不同**：

| 维度 | 立绘 | 3D |
|---|---|---|
| 细节密度 | 皮肤质感、眼神高光、线稿层次可更丰富 | 减面，靠大块体面转折与符号件 |
| 比例 | 头部与眼神可略"肖像化"强调 | 头身比略收束以保证战场占位可读 |
| 装饰 | 可画得更细 | 只保留"能在轮廓上读到的"装饰 |

**验收标准**：遮住立绘只看 3D 剪影+accent 仍能说出是谁；只看立绘仍能感到与战场上"同一套几何与色标"。

### 5.5 LOD 哲学

信息按"威胁与身份"分层衰减，不均匀糊掉：

- **最远仍保留**：整体剪影 + accent 色小块 + 武器主轮廓
- **可先牺牲**：面部微表情、小徽章、细链、布料褶皱纹理
- **最小可读元素**：一个外轮廓 + 一个 accent 点 + 一个武器主向 = 合格。三者缺一即 LOD 设计失败

### 5.6 角色 Accent 色

| 角色原型 | Accent 气质 | 立绘表现 | 3D 表现 |
|---|---|---|---|
| **A 秩序/节拍** | 冰蓝钢（理性、稳定） | 眼神高光与金属边同色 | 刃格、肩扣、细条纹 |
| **B 机动/刃锋** | 琥珀铜（侵略、工业蒸汽） | 唇线/眼底略偏暖增攻击性 | 刃根热段、护手内侧条 |
| **C 工艺/仪式** | 雾紫（神秘但理性） | 仪盘、墨水/刻线色调 | 摆锤坠、圆环仪边缘 |

**禁忌**：三人 accent 不挤在同一色相区间，否则小屏混战失去"找点认人"的效果。

## 6. 环境设计语言 (Environment Design Language)

### 6.1 建筑风格与世界观

**定位：晚期哥特结构骨架 + 工业蒸汽"寄生层"**

这不是"蒸汽朋克主题乐园"——这是一座曾为城市计时的仪式性高塔，在崩塌与多次改建中被齿轮传动、配重、制动与维护走道从内部撑开、外包、再修补。

- **哥特可读性**：尖券、肋架、扶壁、纵向比例、小窗高墙 → "神圣、压迫、时间被制度化"
- **工业可读性**：外露桁架、铆接板、铸铁护栏、滑轮组、管线束 → "人力试图驯服时间与重力"
- **遗迹可读性**：断裂肋架、错位楼层、被齿轮咬穿的墙体 → "崩塌钟楼遗迹"

**文化叙事一句话**：圆（钟面/仪式）代表旧秩序，齿（传动/暴力效率）代表新秩序，摆（垂直轴/重力裁决）代表两者撕扯下的物理真相。

### 6.2 贴图哲学

**手绘 (Hand-painted) Diffuse + 极简材质响应**。

- **为什么（平台）**：微信 WebGL 带宽与 ALU 紧，手绘贴图把信息量集中在剪影与色块，比写实 PBR 更稳
- **为什么（美术）**：可读性优先——格子/平台边缘、危险落差、敌人轮廓必须秒级分辨
- **为什么（叙事）**：冷基底 `#1A2338` 更适合"油画式克制"
- **PBR 仅限点缀**：铸铁/铆钉/少量裸露黄铜轴承一个很窄的 Metallic/Roughness 范围
- **Normal**：仅大尺度结构（砖缝、肋架转折、齿轮厚度），禁止高频噪点铺满
- **自发光**：默认关或极低，仅安全指示、关键交互物、极少仍在滴答的仪表

### 6.3 道具密度规则

| 楼层 | 圆:齿:摆（构图权重） | 密度原则 |
|---|---|---|
| **底层（门厅/传动）** | 圆↑ 齿中 摆低 | 中高密度——每 8-12m 一条信息簇，填充簇用重复模块化件保持节奏 |
| **中层（齿轮中庭）** | 圆中 齿↑ 摆中 | 中密度——走道化、工具化，道具形成"维护工作流程" |
| **上层（钟绳/观测）** | 圆低 齿中 摆↑ | 稀疏——大留白+强垂直引导，小道具只放在决策点 |
| **顶层（Boss）** | 摆↑↑ | 极稀疏+巨型构件——用尺度变化做层差 |

**密度三把扳机**：
1. 遭遇战区域自动进入"稀疏模式"（清掉 30-50% 装饰件）
2. 可能遮挡前摇剪影的悬挂物必须抬高/后移/减透明度
3. 同屏最多 1 个强叙事锚点，其余降级为背景重复件

### 6.4 环境叙事指南

**总原则：每一景只讲半句话，让玩家拼。**

**高信号道具**（优先模块化叙事簇）：
- 圆（钟）：碎裂刻度、被齿轮凿穿的表盘、指向不可能时间的指针
- 齿（传动）：突然终止的链条、卡在墙里的棘轮、过度上紧导致的崩齿
- 摆（垂直轴）：偏离中线的摆轨、被拉断的配重缆、摩擦烧蚀的导轨

**中信号**：地坪材质叠压（旧石+新铁板补丁）、单向通行磨损痕迹

**禁止**：同区域堆叠多个互不相关的重大事件；过度具象的现代符号；强对比色块（留给弹反）

### 6.5 模块化资产策略

**一套模块库 + 三套构图配方 + 少量层专属件**

**模块分层**：
1. **结构母核**（占面最大）：拱券段、直墙段、肋架单元、楼板、楼梯模块
2. **工业寄生件**（中频重复）：桁架短节、铆接板、走道护栏、小型齿轮托架
3. **母题符号件**（低频点睛）：钟面扇段、齿圈弧、摆轨立柱/锤体
4. **叙事簇**（每层 2-3 套预制组合）：如"表盘被咬穿+制动钳+断裂链条"

**层间差异靠三参数**（非换贴图全家桶）：
1. 母题权重（频率与尺度）
2. 破损梯度（裂缝密度、扶壁缺失、楼板悬挑程度）
3. 色温与材质比例（铁板补丁占比上升、石材完整面下降）

**验收标准**：底层一眼读"公共层"，中层"传动维护层"，上层"摆锤裁决层"。若需 UI 文案解释"这是哪"，则模块语法失败。

### 6.6 雨天氛围层 (Rain Atmosphere Layer)

**定位**：雨不是"室外天气插件"，而是钟塔**结构正在失效**的感官证据——水从裂缝、玫瑰窗、管道法兰与齿轮护罩渗入，在石材与钢轨上汇集、滴落、回响。玩家在室内探索与战斗全程与雨共存。

#### 渗水叙事逻辑

- **塔体崩解**：扶壁开裂、灰浆剥落 → 雨水沿竖向结构（井式中庭、缆索井）下行，在转角与低洼处滞留
- **工业接口**：蒸汽阀泄压口、冷凝管外壁、齿轮箱呼吸孔 → 冷凝+喷溅与天然渗水叠加，"机器也在出汗"
- **可读性优先**：渗水痕迹用大色块暗纹 + 明确水迹走向（自上而下的 V 形渍、踢脚线潮线）

#### 按层强度规则

| 楼层 | 视觉主导 | 声音主导 | 体感 |
|---|---|---|---|
| **低层** | 积水、水潭、踢脚潮线、地面弱镜面斑块 | 密闭混响 + 远闷雷雨墙 + 高密度水滴噗嗒 | 闷、重、黏 |
| **中层** | 墙身水痕、窗下积线、间歇性水帘 | 雨击金属/玻璃中频 + 井道回声 | 过渡——可随战斗切换 |
| **高层** | 直接雨声存在感、气流感、窗洞斜向雨丝（极省） | 高频雨刷感 + 风声、垂直空间早期反射 | 尖、透、冷 |

**关卡验收**：每层至少 1 个静息听音点（3-5s），让玩家建立"这一层的雨性格"。

#### 视觉元素（WebGL 友好）

- **水洼**：烘焙或手绘湿度 mask + 简化反射；大椭圆+破碎边，贴地不抢角色剪影
- **湿表面**：粗糙度↑、Specular 变钝、暗部轻微偏青（与钟塔深蓝/钢青灰一致），禁止全屏动态法线水流
- **滴水**：挂点条带 mesh 或循环 UV 水线 + 小片 alpha 涟漪 sprite（生命周期短、总量封顶）
- **齿轮冷凝**：静态水珠簇 + 偶发掉落（事件驱动），可与摆锤/齿轮节拍对齐
- **墙面水迹**：decal 分层（尘→锈→潮），同屏数量写死上限

#### 音频元素（主载体）

- **Bed**：分层远雨墙 / 近檐雨 / 室内尾音三条 bus，按层自动混合
- **滴水节奏**：2-3 种样本做 round-robin，轻微随机间隔，偶发"准节拍"（与 UI 滴答、齿轮错开半拍）
- **垂直空间**：中庭楼梯井用短早期反射 + 低通湿滤波
- **角色交互**：进入/离开水洼 → 轻溅层（按移动速度映射）
- **混音安全**：雨 bed 上限 -6~-10 dBFS，给弹反音效留峰值空间；滴水中频凹陷给关键提示留孔

#### 与冷静舞台规则的关系

- 雨视觉只增强冷底与体积感，不引入新暖色光源
- 水洼镜面只做低频 mood（暗、钝、局部），禁止大面积高对比动态反射
- 与雾协同：灰紫雾 `#3D3A52` 略抬一档即可，避免同时拉满粒子+雾+Bloom

#### 与战斗反馈的声画对位

| 阶段 | 雨声处理 | 画面湿要素 |
|---|---|---|
| **指令/战前** | 满强度 bed + 稳定滴水 | 正常湿表面 |
| **弹反窗口** | 雨 bed −3~−6 dB，滴水低通/短时 mute | 粒子/涟漪触发率减半 |
| **判定瞬间** | 一帧"湿空间抽干"，0.2-0.5s 雨声回填 | 弹反峰值按规则，雨视觉不抢爆灯 |
| **完美弹反后** | 雨声 full return——"世界恢复呼吸" | 可伴随单点大雨滴落地作句号 |

> **一句话**：雨是钟塔损坏与时间渗漏的同伴。下层脚湿、上层耳湿。眼睛用少而准的潮与洼交代，耳朵用分层雨床与滴水节律扛主叙事。弹反窗压低雨声，把对比留给那一次爆灯。

#### 性能约束（WebGL）

- **禁止**：屏幕空间反射、实时平面反射、全场景 GPU 粒子雨、动态水流 UV
- **上限**：同时活跃涟漪 sprite ≤8-12；滴水挂点 ≤20/视野；条带水线用共享材质+GPU instancing
- **降级链**：低端机 → 先关雨丝与涟漪，保留 bed + 偶发滴水；再降为单轨 mono 湿噪声

## 7. UI/HUD 视觉方向 (UI/HUD Visual Direction)

### 7.1 屏幕空间 vs 叙事化

**屏幕空间 HUD 为主（约 85%），极克制叙事化锚点（约 15%）。**

战棋需要稳定可读的状态信息。微信 WebGL 上叙事化 UI（世界空间跟随、透视缩放）会引入字号漂移、遮挡、额外批次。叙事化仅做装饰层：半透明钟盘刻度、细齿轮纹作弱提示，不参与交互命中。

**一句话**：信息像仪表一样稳定；氛围像钟楼一样"在周围"，但不抢读数。

### 7.2 字体方向

**气质**：中性几何 + 轻微工业感（精密仪器读数），避免手写/书法。中文优先思源黑体 / HarmonyOS Sans 等系统友好、Hinting 稳定的字族。

| 层级 | 用途 | 字重 | 字号(dp) |
|---|---|---|---|
| H1 | 模式标题/章节名 | Semibold | 20-22 |
| H2 | 面板标题 | Medium | 18 |
| Body | 规则说明、描述 | Regular | 14-15 |
| UI Label | 按钮、列表项 | Medium | 14 |
| Data | 关键数值（伤害、资源） | Semibold | 16-18 |
| Caption | 次要提示 | Regular | 11-12 |

同一屏最多 3 个字号台阶。中文最小可读不低于 11dp。

### 7.3 图标风格

**单色线框 + 极细面填充（2.5D 扁平）**，禁止重插画图标。

- 小尺寸下图标需形状编码，线框+1px 描边对比更稳
- 图标像仪表符号(glyph)，不是贴纸
- 三档：24dp / 32dp / 48dp，线宽 1.5-2.0dp

### 7.4 动效气质

**机械 + 短促弹性（micro-overshoot），拒绝长弹性果冻。**

- 进入/退出：120-180ms，cubic-out，位移 ≤8-12dp
- 齿轮装饰层：240-400ms 极慢漂移（发条余韵），循环周期 ≥8s
- 焦点切换：90ms 高对比描边亮起 + 30ms 二次稳定（棘轮落位感）
- 禁止：>300ms 弹簧 overshoot、大面积 motion blur

### 7.5 触控规范

| 类型 | 最小命中(dp) | 推荐(dp) | 间距 |
|---|---|---|---|
| 主按钮 | 44 | 48 | ≥8 |
| 次要按钮/图标 | 40 | 44 | ≥8 |
| 棋盘格交互 | — | 格内中心 ≥40（透明热区放大） | 由棋盘规则定 |
| 列表行 | 44高 | 48高 | 行间距 ≥6 |

24dp 视觉图标命中区仍必须 ≥40dp（透明 padding）。高频控件离屏幕边缘 ≥12dp。

### 7.6 UI 与弹反反馈的关联

**HUD 平时"像关机仪表"，完美弹反瞬间"像上弦亮表"。**

- 平时 HUD 对比度压低 10-15%，装饰齿轮层不透明度 ≤6%
- Perfect Parry 窗口内 120-220ms 提升到正常对比
- 弹反条/节拍窗/准星环三选一为主通道，避免三路同炸
- 色语义锁定：正向奖励只用 `#C9A227` 小面积高光，危险用 `#E85D2C` 细线
- 节奏同步：HUD 刻度推进与战斗窗口帧对齐（±1帧视觉容差），用一次性咔嗒位移动画（60-90ms）

## 8. 资产标准 (Asset Standards) — 微信小游戏 WebGL 专版

**平台前提**：WebGL 1.0 为主、无原生 GPU 直通、触控-only、主包代码 ≤4MB、含分包总包体 ≤20MB（大资源走 CDN）。
**总原则**：宁可少张图、少材质、少骨骼、少物体，也不在单帧上堆高清+多 DrawCall。

### 8.1 多边形预算

| 类别 | 三角面预算 | 硬顶 |
|---|---|---|
| **可玩角色** | 2,500–4,000 | 4,500 |
| **普通敌人** | 1,800–3,000 | 3,500 |
| **精英/大型杂兵** | 3,000–4,500 | 5,000 |
| **Boss（单体）** | 6,000–10,000 | 12,000 |
| **场景静态几何（单战斗舞台）** | 28,000–45,000 | 50,000 |
| **小道具/可拾取** | ≤400 | — |
| **UI 模型化装饰** | ≤800 | — |

**整场战斗"角色+场景"建议 ≤50k-55k tris。**

**LOD 强制**：角色至少 2 档 LOD；LOD1 约 LOD0 的 45-60%；最远档 800-1,500 tris 级剪影。

### 8.2 贴图分辨率

| 层级 | 分辨率 | 用途 |
|---|---|---|
| **T0（默认，70%+ 贴图）** | **256×256** | 敌人、环境模块、道具、平铺材质 |
| **T1** | **512×512** | 可玩角色主 Albedo、Boss 主体 |
| **T2（特许，需 TA 签字）** | **512 合并通道** 或 **单张 1024 仅限全屏 UI/启动图** | 战斗内 3D 世界不放 1024 常驻 |

- 角色：主贴图 512 上限，目标 ≤2 张纹理/角色（能 1 张则 1 张）
- 法线：默认关或仅 Boss/主角配一张低细节 512 法线，其余用手绘明暗+顶点法线
- 同类材质强制 Atlas，禁止同一视觉密度拆十几张小图

### 8.3 材质槽位

| 对象 | 材质球数量 | 贴图组合 |
|---|---|---|
| 可玩角色 | ≤2 | 每材质 ≤3 张纹理，SetPass 目标 ≤2/角色 |
| 敌人 | 1（优先） | ≤2 张纹理/材质 |
| Boss | ≤3 | 仅 1 个允许略复杂（溶解/阶段） |
| 场景模块 | 每模块 1 | 大面与细节块共用同一 Shader 变体 |
| 特效片 | 粒子统一 Add/Alpha 各 1 套 | 禁止每特效单独新材质球 |

Shader 优先 Mobile/Unlit 或少量 URP Lit 变体，禁止多分支多 Pass。

### 8.4 文件格式与命名

- 模型：FBX，源 .blend 不进包
- 贴图：PNG 源 → 导入压缩 ASTC/ETC2，禁用未压缩 TGA 进包体
- 命名：`[类型]_[名称]_[变体]_lod[N]`，贴图后缀 `_A` `_N` `_M`
- 命名需体现 LOD/Atlas 归属

### 8.5 Draw Call 预算

| 场景 | 目标 | 硬顶 |
|---|---|---|
| **战斗（常态）** | 30–45 | 55 |
| **战斗峰值（完美弹反 0.2-0.4s）** | +8-15 临时 | 单帧硬顶 70，2 帧内回落 |
| **探索（箱庭）** | 25–40 | 50 |
| **纯 UI 菜单** | 15–28 | 35 |

配套：静态批处理 / GPU Instancing / 图集合并 / 减少实时阴影投射体 / 控制 SkinnedMesh 数量。

### 8.6 内存上限

| 指标 | 值 |
|---|---|
| **目标峰值** | ≤280 MB |
| **硬顶** | ≤320 MB |
| **绝对红线** | 350 MB（仅允许极短瞬时尖峰） |

经验分配：纹理 120-160 MB / 网格+动画+音频 40-80 MB / 留给 GC+微信容器+JS ≥80-100 MB。

加载策略：分关分包，不进战斗不驻留战斗纹理，Boss 资源进房流式加载、打完显式卸载。

### 8.7 动画与骨骼预算

| 项目 | 预算 | 硬顶 |
|---|---|---|
| 骨骼数（可玩角色） | ≤40 | 48 |
| 骨骼数（敌人） | ≤28 | 32 |
| 骨骼数（Boss） | ≤64 | 72 |
| 同屏 SkinnedMeshRenderer | ≤6 | 8 |
| 每角色活动 Clip 层 | ≤2 | — |
| 关键帧密度 | 每秒 ≤15-20 keys | — |
| 单角色常驻动画数据 | ≤1.5-3 MB 压缩 | Boss ≤5-8 MB |

采样率导出 30fps 为主。关键打击帧用事件帧而非加密钥密度。

### 8.8 音频

| 类型 | 格式/码率 | 体积上限 |
|---|---|---|
| 循环 BGM（战斗） | AAC 96-128kbps 立体声 | ≤2.5 MB，首包 ≤1.5 MB |
| 循环 BGM（探索） | AAC 64-96kbps | ≤2 MB |
| 剧情配乐段 | AAC 96kbps | ≤1 MB/段 |
| 音效 SFX（多数） | 单声道 ADPCM/AAC 低码率 | ≤80 KB（硬顶 150 KB） |
| 重低音打击/Boss 吼 | 略升码率 | ≤250 KB（硬顶 350 KB） |
| 同场景同时解码声道 | — | ≤4-5 条 |

原则：短、单声道、低采样率（22.05kHz 可接受）优先。预加载列表最小化。

## 9. 参考方向 (Reference Direction)

5 条参考各填补一个独立视觉需求，互不重叠。

### 9.1 《光与影：33号远征队》(Clair Obscur: Expedition 33)

**抽取**：油画式笔触感+定向高光（体积由笔触方向而非纯法线读出）；雾体积中的色温分层（冷暖分离标深度）；威胁提示与画面焦点同轴（光源/笔触密度向威胁源汇聚）。

**避免**：全盘复刻其历史混搭符号堆叠（会稀释"哥特钟塔+工业蒸汽"的锚点）；把"印象派"做成糊边低分辨率（笔触服务于轮廓可读，不掩盖低模拓扑）。

**为何关键**：证明高风格化材质可与强阅读性的预兆构图并存——这正是微信小屏上最难兼顾的一点。

### 9.2 《再见狂野之心》(Sayonara Wild Hearts, Simogo)

**抽取**：饱和度与色相偏移作为"强度包络"（高潮前系统性提高互补色对比）；低模几何的硬切阴影/平面色块分区（小屏雨中剪影仍稳定）；镜头与色相同步的"节拍剪辑"（机制切换用一次性全屏色偏作章节标点）。

**避免**：照搬霓虹都市+电音 MV 题材符号（与哥特叙事错位）；持续高频频闪与过度饱和（性能与审核风险）。

**为何关键**：提供可控的色与对比度曲线，在"压抑基调"与"弹反高潮"之间做可复用的视觉语法。

### 9.3 《GNOSIA》

**抽取**：肖像的"非对称五官应力"（轻微不对称表达怀疑/敌意）；线稿层级固定（外轮廓线宽 > 内结构线 > 装饰线，阴影用平涂阶+硬边）；背景与立绘的"材质隔离"（立绘保留纸感，背景用不同颗粒）。

**避免**：把 GNOSIA 式立绘做成与 3D 场景同一光照模型（应接受"剧场式打光"）；过度二次元萌系符号削弱哥特成人戏剧张力。

**为何关键**：证明强识别度头像在小分辨率下仍可承担叙事与阵营暗示，直接支撑"角色锚定情感"支柱。

### 9.4 《哨兵少女》1 & 2 (Sentinel Girls)

**抽取**：工业背景的"模块化重复件"构图（重复韵律+一处破型建立记忆点）；金属的"锈渍走向"作为引导线（锈迹/水痕沿重力画成隐含视觉引导）；局部高饱和警示色（阀门/压力表/警示条用小面积高饱和嵌在铁灰里）。

**避免**：过度脏灰导致画面无主次（灰要有阶）；把蒸汽朋克做成无功能的装饰堆料（每根管道暗示流向或分区）。

**为何关键**：补足"工业层如何与建筑体量咬合"的具体画法——哥特钟塔若只有石材会单薄。

### 9.5 《Hi-Fi Rush》

**抽取**：打击/格挡成功的"多轨反馈叠帧"（同帧内组合局部色相闪变+速度线+UI 刻度脉冲）；血条/行动条在成功判定时出现窄带宽形变（与音效包络对齐）；可格挡窗口内的周期性 UI 微动（训练潜意识对齐）。

**避免**：整体滑向美式卡通渲染与过量漫画拟声字（与手绘低模哥特气质冲突）；长时间强节奏 UI 运动造成视觉疲劳。

**为何关键**：提供"如何把瞬时成功反馈编码成可学习的视听模式"——实时弹反在弱设备上也要一下就读懂。

### 参考覆盖校验

| 参考 | 填补的独立视觉需求 |
|---|---|
| E33 | 风格化材质 + 预兆与构图同轴的可读性 |
| Sayonara Wild Hearts | 强度驱动的色相/饱和度包络与段落标点 |
| GNOSIA | 小分辨率肖像叙事与线稿层级 |
| Sentinel Girls | 工业蒸汽环境与引导性细节 |
| Hi-Fi Rush | 格挡/打击的多轨视听反馈语法 |
