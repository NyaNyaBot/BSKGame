## Purpose & Player Need

主菜单是微信 WebGL **触控**环境下的首个枢纽 screen：让玩家在无开发者指导下完成 **「从可选战役中选定一场 → 确认 → 进入场景加载」**，并可触及 **设置**、**关于**；不承担叙事演出的主要职责——**功能优先**：文案与布局以可读、可点、路径短为先；钟楼基调与角色氛围可作为后续 polish，不在本节必选范围内。

**玩家要完成的事**

| 目标 | 说明 |
|------|------|
| **开战** | 进入战役列表 → 选定条目 → 确认 → 触发加载（对齐 Vertical Slice / 门禁「启动 → 战斗」） |
| **次要入口** | 打开设置、关于，且不阻断返回主战路径 |
| **理解边界** | 在无长线存档的 MVP 阶段，明确「当前可从菜单启动的可玩内容」 |

**若本屏缺失或难用**

- 无法在 UX 规格层面验收「启动 → 战斗」链路；与 `production-gate-checks` 中对 **main-menu** 文档缺口不一致。
- 触控误触或未确认的战役直接进入加载，会破坏可控性与 QA 复现。

---

## Player Context on Arrival

- **何时首次见到**：小游戏启动流程（Procedure / 资源就绪）结束后进入主菜单；此前玩家可能经历加载或资源更新，主导情绪是「等待结束，想确认能玩什么」。  
- **上一动作**：包含两类——**(1) 冷启动**后被送达菜单；**(2) 自战斗/结算/暂停等流程选择「返回标题」**（与 **Navigation Position / Entry** 中的双入口一致；具体触发以工程实现为准）。  
- **情绪与设计假设**：中性略急——优先看到**清晰可点项**与**下一步**；本节遵循 **功能优先**，不在首屏强加叙事演出或长动画。  
- **自愿性**：默认视为游戏将玩家送达此处（非自愿探索中途）；玩家可随时通过列表与按钮主动选择开战或进入次要界面。

---

## Navigation Position

主菜单是 **双入口的根枢纽**：在「可从菜单发起的玩家流程」中处于核心节点——既承接 **启动壳结束后的首个可操作菜单**，也承接 **自游玩流程返回标题** 的路径（结算页、暂停菜单或等价 UI 上的「返回主菜单」按钮；具体挂载 screen 以实现为准）。  

除微信/系统级覆盖（键盘、授权、后台恢复）外，**不设更高层的常驻游戏 UI 父级**；设置、关于为子屏（modal 或独立 UIForm），战役选择为主菜单内的 **模式/子面板**（见 Layout）。

## Entry & Exit Points

### Entry（到达）

| Entry Source | Trigger | Player carries this context |
|--------------|---------|-----------------------------|
| 冷启动 / 启动流程结束 | Procedure 或等价流程调用 `EnterMenu`，打开 `MenuForm` | 无战役选中；可能带有资源更新刚完成的预期 |
| 返回标题 | 战斗结算（Retry/Exit 之外的「回标题」）、暂停菜单「返回主菜单」、或其它流程显式请求回菜单（以实现为准） | **必须丢弃或冻结上一战斗上下文**，不应携带未完成回合输入；**战役列表选中态保留**（便于立刻重打同一关），但若 UI 当下停在普通面板则玩家仍须再次进入战役面板后方可确认 |

### Exit（离开）

| Exit Destination | Trigger | Notes |
|------------------|---------|-------|
| 战斗场景加载 | 战役列表中选战役 → **确认开战**（如 `OnBattleSelectConfirm`） | 进入 `TempGameState` / 场景切换链路；输入应按场景管理 GDD 在加载期进入 `Suspended` |
| 设置 | 主菜单「设置」→ `SettingForm` | 关闭设置后应回到主菜单同一状态层级 |
| 关于 | 主菜单「关于」→ `AboutForm` | 同上 |
| 留在主菜单（子状态切换） | 「进入战役列表」/「退出战役列表」 | 仍在 `MenuForm` 内切换面板；确认条目不带走加载 |
| （可选）退出小游戏 | 「退出」若启用 | 微信环境下常以平台行为为准；实现若占位则须在 UI 标明 |

## Layout Specification

### Information Hierarchy

（与你的选项 **B：开战与次要入口同级视觉权重** 对齐；功能优先。）

| 优先级 | 信息 / 动作 | 说明 |
|--------|-------------|------|
| **P0（同一扫视层）** | 进入战役选择、设置、关于 | 首屏（普通面板）须在同一视线层级可读、可点；不要求叙事大图抢占焦点 |
| **P0（流程内）** | 战役列表可读标签、选中态、确认开战 | 进入「战役选择」子面板后，列表 + 确认为该模式下的焦点 |
| **P1** | 退出 / 离开小游戏 | 微信语境常见弱化；若显示则不得遮挡 P0 触控 |
| **P2（占位）** | 版本号、构建标识 | 仅开发构建或「关于」内 |

### Layout Zones

| Zone | 职责 | 可见性 |
|------|------|--------|
| **Safe Area 边缘留白** | 避让刘海、底部手势条 | 始终 |
| **顶部带（可选）** | 游戏标题或极简标识；不占大块插画预算 | 普通面板默认 |
| **主行动带** | 并排或大间距纵向排列：**进入战役选择**、**设置**、**关于**；（**退出**若启用） | 普通面板 `NormalMenuPanel` |
| **战役选择面板** | 滚动列表 + 返回 + **确认开战** | `SelectBattle` 模式；与普通面板互斥显示 |
| **底部留白** | 防止误触系统手势 | 始终 |

| Zone | 组件 | 交互 | 备注 |
|------|------|------|------|

| 主行动带 | 按钮「设置」 | 点按 → 打开 `SettingForm` | |
| 主行动带 | 按钮「关于」 | 点按 → 打开 `AboutForm` | |
| 主行动带 | 按钮「退出」（可选） | 点按 → 平台退出或占位 | 当前实现可能注释 |

## States & Variants

| State / Variant | Trigger | What Changes |
|-----------------|---------|--------------|
| **菜单战役数据载入中** | `MenuForm` 已呈现，但 `AvailableBattles`（或等价数据源）尚未就绪（异步解析 / IO） | 显示 **Loading**（全屏或就地 Spinner/Skeleton）；**禁用**「进入战役选择」与一切开战路径；不可与「致命错误」同时占用同一帧——载入完成后进入 Default 或致命态 |
| **Default — 普通面板** | 战役数据已就绪且可用条目 **> 0** | 显示主行动带：进入战役选择 / 设置 / 关于（及可选退出） |
| **战役选择模式** | 点「进入战役选择」 | 显示滚动列表、返回、确认；普通面板隐藏 |
| **选中战役未确认** | 列表点选一行 | 确认按钮可用；`BattleConfirm` 区域可见（对齐现有 CanvasGroup alpha） |
| **加载 / 场景切换中** | 已确认开战，`TempGameState` 发起切场景 | 主菜单应阻止重复确认（防抖）；视觉可由全局 Loading 承接（见场景管理 GDD） |
| **配置致命：无可用战役**（你已选 **C**） | `AvailableBattles` 为空或战役数据载入失败 | **整页阻塞**：中央错误说明 + **重试**（重新请求/刷新数据表或重启菜单流程）；**不提供**战役列表、**不提供**设置/关于入口（已定案）；若启用退出则仅此一并展示 |
| **子屏覆盖** | 打开设置 / 关于 | 主菜单保留在栈下；关闭子屏回到菜单原状态 |

## Interaction Map

**输入基准**：`technical-preferences` — **Touch Full**；无手柄。主菜单按钮以 **轻触点按**（UGUI `Button` / `onClick`）为主；不要求 hover。**不与**战斗「Timing inputs → PointerDown」混用：菜单不走 `InputHitAreaRegistry`；设置/关于为 UIFrame 子窗体，叠加顺序与模态遮挡以实现为准（参见文档头 **Interaction Patterns** 说明）。

**Loading 态**：除「重试/取消」（若有）外，主按钮不可点；避免玩家在列表未就绪时进入战役模式。

| 组件 / 区域 | 动作 | 即时反馈 | 结果 |
|-------------|------|-----------|------|
| 进入战役选择 | Tap | 按下态 / 可选短音效 | 切入战役选择布局 |
| 战役列表项 | Tap | 选中高亮 | 写入当前选中 `DRBattle` |
| 确认开战 | Tap | 按下态 | 校验已选 → `RequestStartBattle`；非法则 Warning，不加载 |
| 返回（战役模式） | Tap | 按下态 | 回普通面板；**不清空已选战役**（已定案），确认条目不带走加载直至下次确认 |
| 设置 / 关于 | Tap | 按下态 | `OpenUIForm` 对应 UIForm |
| 退出（若启用） | Tap | 按下态 | 平台退出或对话框 |
| **致命错误屏 — 重试** | Tap | 按下态 | 重新拉取战役列表或重新进入菜单初始化 |
| **致命错误屏 — 退出（若有）** | Tap | — | 关闭小游戏 |

## Transitions & Animations

- **功能优先**：普通面板 ↔ 战役选择以 **即时切换** 或 **≤150ms 淡变**（`CanvasGroup.alpha`）即可，不做长叙事过渡。
- **进入子屏（设置/关于）**：遵循 UIFrame 默认打开动画；不得遮挡致命错误屏逻辑。
- **减弱动效**：若全局启用 low-motion（反馈分级），主菜单仅保留淡变或不透明度跳变，禁用弹性缩放。

## Data & Loading Assumptions

| 假设 | 说明 |
|------|------|
| **A1（默认 MVP）** | `AvailableBattles` 在 `MenuForm` **首次可交互前**已由 `MenuModel`/数据表管线 **同步**就绪 —— 则不经过「菜单战役数据载入中」状态，直接从 Default 或致命态开始。 |
| **A2（异步）** | 若管线改为异步：必须呈现 **States** 中的「菜单战役数据载入中」；超时或失败转入 **致命错误**（`reason=load_failed`），不得静默空白。 |

列表刷新 **触发**：菜单打开、`ui_main_menu_fatal_retry` 成功后、或工程定义的重新进入菜单事件。

## Data Requirements

| Data | Source System | Read / Write | 更新触发 | 不可用 / Null |
|------|---------------|--------------|----------|----------------|
| 可用战役列表 | `MenuModel` / 数据表管线（`DRBattle`） | Read | 菜单打开、重试成功、重新进入菜单 | 载入失败→致命；载入中→Loading 态（见 **Data & Loading Assumptions**）；就绪且 **count=0**→致命 |

| 场景路由 | `TempGameState` / Scene 表 | Write（开战路径） | 确认开战 | N/A |

## Accessibility

对齐 **`design/accessibility-requirements.md` — Basic**：

- 所有 **P0 按钮**触控目标 ≥ **88dp**（与战斗 HUD 触区下限一致）；主行动带按钮间距足够避免误触。
- **选中战役**除颜色外须有 **描边/图标/字号变化** 之一，避免纯依赖色条。
- **致命错误**文案须可读对比度；重试按钮满足最小目标尺寸。
- 不设仅凭音频完成菜单导航（小游戏触控语境）。

## Localization Considerations

- 按钮与致命错误文案预留 **中文 MVP**；扩展德语等时需承受约 **40% 文案膨胀**——主按钮建议单行省略策略或用两行自适应。
- 战役项当前若以路径字符串展示，本地化阶段应替换为 **关卡显示名**键。

**文案长度指引**（非硬编码引擎限制；布局验收用）：

| 元件 | 中文 MVP 参考长度 | 布局预留（约 +40% 语系） |
|------|-------------------|---------------------------|
| 主行动带按钮 | ≤8 字 | ≤12 字或双行 |
| 致命错误标题 | ≤18 字 | 单行或折行 |
| 致命错误正文 | 1–3 短句 | 允许自动折行 |
| 战役列表单行标签 | ≤36 字（路径占位） | 显示名键建议 ≤24 字等效宽 |

## Acceptance Criteria

- [ ] 冷启动可在 **无口述指导** 下完成：**进入战役选择 → 选中 → 确认 → 进入加载**（Vertical Slice 验收）。
- [ ] **双入口 — 返回标题**（当构建提供「返回主菜单」时必测）：返回后主菜单可交互；`ui_main_menu_open` 的 `entry_reason=return_title`（或等价调试字段）可观测；**先前选中的战役仍保留**；玩家从普通面板再次进入战役列表后可直接「确认开战」而无需强制重选（除非主动改选）。
- [ ] **未选中战役时**，点确认不得发起场景加载，且玩家收到明确反馈（日志/Toast/Warn 任一可测）。
- [ ] `AvailableBattles` 为空或载入失败时呈现 **整页致命错误 + 重试**，且无法进入战役列表。
- [ ] （若启用异步载入 A2）数据未就绪时出现 **Loading**，期间主按钮不可点；就绪后自动进入 Default 或致命态。
- [ ] 设置、关于打开关闭后主菜单状态可预期（无重复叠加、无失效按钮）。
- [ ] 主要按钮在目标宽高比下处于 **安全区内**，且不小于 **88dp** 触控目标。
- [ ] `OpenUIForm` 打开 `MenuForm` 至首帧可交互：**≤ 500ms**（中低端 WebGL 为努力目标；超时记入 QA）。
