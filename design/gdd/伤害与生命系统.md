# 伤害与生命系统

> **Status**: Approved
> **Author**: Sulequan + Agents
> **Last Updated**: 2026-04-27
> **Implements Pillar**: 精准即快感；角色即动力；小而精致

## Summary

伤害与生命系统负责把攻击、弹反结果和反击动作转化为确定的 HP 变化、死亡状态和可观察事件。它是战斗后果的唯一写入口：实时弹反系统只输出 `damageMultiplier`，回合管理器只读取胜负状态，角色数据模型只保存 HP 与状态字段；最终伤害、HP clamp、Defeated 判定、同 tick 伤害顺序和死亡事件都由本系统拥有。

> **Quick reference** — Layer: `Core` · Priority: `MVP` · Key deps: `角色数据模型`, `回合管理器`, `实时弹反系统`

## Overview

本系统把“有没有挡住”变成玩家真正感受到的战斗代价。MVP 只支持基础物理伤害、弹反倍率、基础防御、无治疗、无护盾、无元素和无持续伤害。它必须精确消费 `ParryResolved.damageMultiplier`：`PerfectParry=0.0` 无伤，`NormalParry=0.5` 半伤，`FailedParry=1.0` 全伤。它不决定攻击何时发生、不播放受击表现、不推进回合，只负责可回放的数值结果与生命状态。

## Player Fantasy

玩家应该清楚感到“精准守护真的保护了角色”。完美弹反不是一个华丽但数值模糊的演出，而是明确地让当前攻击无伤；普通弹反保住了命但仍有疼痛代价；失败则让角色真实承受后果。生命系统服务“角色即动力”：HP 不是抽象资源，而是玩家正在守护的伙伴状态。

## Detailed Design

### Core Rules

1. **本系统是 HP 写入唯一入口。** 其他系统不得直接修改 `CharacterRuntimeInstance.CurrentHp`。
2. **所有伤害请求必须结构化。** 伤害来源、目标、基础伤害、倍率、来源事件和场景/战斗上下文必须可追踪。
3. **弹反倍率必须被完整消费。** `ParryResolved.damageMultiplier` 乘入最终伤害公式，且不得被回合管理器或反馈系统重写。
4. **MVP 只支持非负即时伤害。** 治疗、护盾、DOT、吸血、元素克制和复活均不在 MVP。
5. **防御只做线性减伤。** 最终伤害不能低于 `min_damage_after_defense`，除非弹反倍率为 0。
6. **HP 写入必须 clamp。** 使用角色数据模型的 `current_hp_clamp`，结果范围为 `0..EffectiveMaxHp`。
7. **死亡判定由本系统拥有。** HP 从 `>0` 变为 `0` 时广播 `CharacterDefeated`，并把角色状态置为 `Defeated`。
8. **死亡不是删除。** `Removed` 仍由回合/场景流程决定，便于迟到事件过滤和战斗结算。
9. **同 tick 胜负优先级接受回合管理器约定。** MVP 中玩家和敌人同 tick 全灭时，`Defeat` 优先。
10. **伤害结算必须幂等。** 同一 `damageRequestId` 或同一 `resolutionId` 派生的伤害不得重复应用。

### States and Transitions

| State | Entry Condition | Exit Condition | Behavior |
|---|---|---|---|
| `Healthy` | HP > 低血阈值 | HP 降到低血阈值或 0 | 可行动、可受击 |
| `LowHp` | HP > 0 且 `hp_ratio <= low_hp_threshold` | HP 回到阈值以上或变 0 | 供 UI/反馈显示危险状态 |
| `DamageResolving` | 收到合法 `DamageRequest` | HP 写入完成 | 锁定同一请求，计算最终伤害 |
| `Defeated` | HP 写入后为 0 | 场景重试/复活/卸载 | 不可行动，默认不可作为普通目标 |
| `InvalidTarget` | 目标不可受击、场景过期或已 Removed | 请求被拒绝 | 不修改 HP，记录 rejected |

## Formulas

### Final Damage

The `final_damage` formula is defined as:

`final_damage = 0 if damage_multiplier == 0; else max(min_damage_after_defense, round_half_up(max(0, base_damage - effective_defense) * damage_multiplier))`

**Variables:**
| Variable | Symbol | Type | Range | Description |
|---|---|---|---|---|
| 基础伤害 | `base_damage` | int | `0-999` | 攻击或技能提供 |
| 有效防御 | `effective_defense` | int | `0-999` | 角色快照 |
| 伤害倍率 | `damage_multiplier` | float | `0.0-5.0` | 弹反或技能倍率 |
| 防御后最小伤害 | `min_damage_after_defense` | int | `1-10` | 非 0 倍率时至少造成的伤害 |

**Output Range:** `0-9999`。  
**Example:** `base=120`、`defense=20`、`damageMultiplier=0.5`，最终伤害 `50`；若倍率为 `0.0`，最终伤害 `0`。

### HP After Damage

The `hp_after_damage` formula is defined as:

`hp_after_damage = clamp(current_hp - final_damage, 0, effective_max_hp)`

**Variables:**
| Variable | Symbol | Type | Range | Description |
|---|---|---|---|---|
| 当前 HP | `current_hp` | int | `0-999` | 角色当前生命 |
| 最终伤害 | `final_damage` | int | `0-9999` | 来自 final damage |
| 有效最大 HP | `effective_max_hp` | int | `1-999` | 角色快照 |

**Output Range:** `0-effective_max_hp`。  
**Example:** HP `60`，最终伤害 `80`，输出 `0`。

### Is Defeated

The `is_defeated` formula is defined as:

`is_defeated = hp_before > 0 && hp_after == 0 && can_defeat`

**Variables:**
| Variable | Symbol | Type | Range | Description |
|---|---|---|---|---|
| 伤害前 HP | `hp_before` | int | `0-999` | 写入前 |
| 伤害后 HP | `hp_after` | int | `0-999` | 写入后 |
| 允许击败 | `can_defeat` | bool | `true/false` | MVP 默认 true |

**Output Range:** `true / false`。  
**Example:** `hp_before=10`、`hp_after=0`、`can_defeat=true`，触发死亡。

## Edge Cases

- **If `damageMultiplier=0`**: 最终伤害为 0，不触发最小伤害。
- **If `baseDamage <= effectiveDefense` 且 multiplier > 0**: 造成 `min_damage_after_defense`。
- **If 目标 `CanReceiveDamage=false`**: 拒绝请求，广播 `DamageRejected(reason=TargetCannotReceiveDamage)`。
- **If 目标已 `Defeated` 或 `Removed`**: 拒绝重复伤害，不重复死亡事件。
- **If 同一 `damageRequestId` 重复到达**: 返回第一次结果或拒绝为 duplicate，不二次扣血。
- **If 场景或战斗上下文过期**: 拒绝请求，不修改 HP。
- **If `ParryResolved(FailedParry)` 到达**: 使用 `damageMultiplier=1.0` 结算完整伤害。
- **If `ParryResolved(NormalParry)` 到达**: 使用 `damageMultiplier=0.5` 结算半伤。
- **If `ParryResolved(PerfectParry)` 到达**: 使用 `damageMultiplier=0.0`，不扣 HP。
- **If 玩家和敌人同 tick 都进入 `Defeated`**: 本系统都广播死亡事件，回合管理器按 MVP 规则判 `Defeat` 优先。

## Tuning Knobs

| Parameter | Current Value | Safe Range | Effect of Increase | Effect of Decrease |
|---|---:|---:|---|---|
| `min_damage_after_defense` | `1` | `1-10` | 防御不易完全抵消伤害 | 高防更强 |
| `low_hp_threshold` | `0.3` | `0.2-0.5` | 更早显示危险 | 危险提示更晚 |
| `damageMultiplier.NormalParry` | `0.5` | `0.25-0.75` | 普通弹反更痛 | 普通弹反更接近保命 |
| `damageMultiplier.FailedParry` | `1.0` | `1.0` | 固定完整伤害 | 固定完整伤害 |

## Visual/Audio Requirements

本系统只发事件，不直接播放表现。反馈系统根据 `DamageApplied.finalDamage`、`damageMultiplier`、`wasDefeated` 决定受击、无伤、死亡或低血反馈。

| Event | Visual Feedback | Audio Feedback | Priority |
|---|---|---|---|
| `DamageApplied(finalDamage=0)` | 可显示无伤/Perfect 保护结果 | 由弹反反馈负责 | Medium |
| `DamageApplied(finalDamage>0)` | 受击、HP 扣减、轻震 | 受击音 | High |
| `LowHpEntered` | HP UI 危险态 | 可选低血 cue | Medium |
| `CharacterDefeated` | 倒下/退场表现 | 倒下音效 | Critical |

## UI Requirements

| Information | Display Location | Update Frequency | Condition |
|---|---|---|---|
| 当前 HP / Max HP | 战斗 HUD 角色状态区 | `DamageApplied` 后 | 目标可见 |
| 伤害数字 | 角色附近或 debug overlay | 可选，MVP 可 debug-only | 伤害发生 |

## Acceptance Criteria

- **GIVEN** `PerfectParry` 的 `ParryResolved.damageMultiplier=0.0`，**WHEN** 生成伤害请求，**THEN** `finalDamage=0` 且目标 HP 不变。
- **GIVEN** `NormalParry` 的 `damageMultiplier=0.5`，**WHEN** `baseDamage=120`、`Defense=20`，**THEN** `finalDamage=50`。
- **GIVEN** `FailedParry` 的 `damageMultiplier=1.0`，**WHEN** 结算，**THEN** 目标承受完整防御后伤害。
- **GIVEN** `baseDamage <= Defense` 且倍率非 0，**WHEN** 结算，**THEN** 最终伤害为 `min_damage_after_defense`。
- **GIVEN** 目标 HP 被扣到 0，**WHEN** `canDefeat=true`，**THEN** 广播一次 `CharacterDefeated` 并设置 RuntimeState=`Defeated`。
- **GIVEN** 同一 `damageRequestId` 重复到达，**WHEN** 处理第二次，**THEN** 不重复扣 HP 或重复死亡事件。
- **GIVEN** 场景上下文过期，**WHEN** 伤害请求到达，**THEN** 拒绝并不修改 HP。
- **GIVEN** 玩家和敌人在同一 tick 被击败，**WHEN** 回合管理器读取状态，**THEN** 本系统提供双方死亡事件，胜负优先级由回合管理器判定为 Defeat。
- **GIVEN** 连续 100 次伤害自动化测试，**WHEN** 随机 baseDamage/Defense/multiplier 输入，**THEN** HP 不低于 0、不高于 MaxHp，死亡事件最多一次。
