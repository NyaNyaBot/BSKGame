# 场景管理

> **Status**: Approved
> **Author**: Sulequan + Agents
> **Last Updated**: 2026-04-27
> **Implements Pillar**: 小而精致；层层递进

## Summary

场景管理负责在《回响之刃》的探索、战斗、Boss、休息点和结局片段之间创建、切换和清理运行上下文。它确保每次场景进入都有明确的输入上下文、角色实例、资源加载状态和退出路径，避免弹反、UI、音频或战斗事件从上一个场景残留到下一个场景。

> **Quick reference** — Layer: `Foundation` · Priority: `MVP` · Key deps: `None`

## Overview

场景管理是游戏流程的空间与生命周期管理层。玩家不会直接看到“场景管理器”，但会体验到稳定的探索到战斗切换、Boss 进入、失败重试和楼层推进。MVP 只需要支持一个钟楼楼层、两场遭遇战、一个 Boss 战和必要的加载/清理流程；但它必须给输入、角色、回合、音频、UI 和战斗反馈提供可靠的场景边界。

## Player Fantasy

玩家应该感觉自己在一座连续、克制、精心编排的钟楼中前进，而不是在一堆技术场景之间跳转。场景切换要服务“小而精致”：进入战斗时节奏清楚，失败后能快速重试，退出战斗后不会有残留 UI、残留音效或上一次弹反事件污染下一次体验。

## Detailed Design

### Core Rules

1. **每个可运行场景必须有 `SceneContext`。** 它记录场景 ID、场景类型、加载状态、输入上下文、角色实例集合、UI 层和音频环境。
2. **MVP 场景类型为 `Boot`、`Exploration`、`Battle`、`BossBattle`、`RestPoint`、`Ending`、`Loading`。**
3. **场景切换必须有明确阶段。** 请求、预加载、冻结当前输入、卸载旧上下文、加载新上下文、激活输入、完成。
4. **场景切换期间不得生成战斗输入。** 输入系统必须进入 `Suspended` 或目标场景指定的输入上下文。
5. **旧场景事件不得污染新场景。** 所有跨场景事件必须携带 `sceneContextId`；迟到事件若不匹配当前上下文则被拒绝。
6. **战斗场景创建角色运行时实例。** 场景管理负责请求角色数据模型创建实例集合；伤害、回合和弹反只引用这些实例。
7. **战斗结束必须清理临时系统。** 回合队列、弹反 active segment、输入触区、战斗 HUD、VFX/SFX 实例和临时角色状态必须在离开战斗时清空。
8. **失败重试是 MVP 必需路径。** 遭遇战失败可从该战斗开始重试；Boss 可从 Boss 战开始重试，不要求整层重载。
9. **场景管理不拥有战斗胜负规则。** 战斗系统通知胜负；场景管理只根据结果切换到指定后续场景或重试。
10. **加载进度必须可观测。** 即使 MVP 使用小场景快速加载，也要输出 `SceneLoadProgress`，供 UI 和 QA 使用。

### States and Transitions


| State           | Entry Condition     | Exit Condition        | Behavior               |
| --------------- | ------------------- | --------------------- | ---------------------- |
| `Idle`          | 无 active scene，或启动前 | 收到 `LoadSceneRequest` | 不接收玩法输入                |
| `PreparingLoad` | 收到加载请求              | 依赖资源请求发出              | 冻结当前输入，记录目标 `sceneId`  |
| `Loading`       | 资源加载中               | 必需资源加载完成或失败           | 更新 `SceneLoadProgress` |
| `Activating`    | 新场景资源可用             | `SceneContext` 创建完成   | 创建上下文、角色实例、UI、音频环境     |
| `Active`        | 新场景激活完成             | 收到切换、失败、胜利或退出请求       | 允许目标场景输入和系统更新          |
| `Suspending`    | 暂停菜单、平台后台或切换准备      | 恢复或进入卸载               | 暂停输入和战斗时钟              |
| `Unloading`     | 离开当前场景              | 清理完成                  | 销毁临时上下文、触区、事件订阅和表现对象   |
| `Failed`        | 加载失败或上下文创建失败        | 重试或返回安全场景             | 禁止进入半初始化玩法             |

## Formulas

### Scene Load Progress

The `scene_load_progress` formula is defined as:

`scene_load_progress = loaded_required_units / total_required_units`

**Variables:**


| Variable | Symbol                  | Type  | Range                    | Description     |
| -------- | ----------------------- | ----- | ------------------------ | --------------- |
| 已加载必需单元  | `loaded_required_units` | int   | `0-total_required_units` | 已完成加载的必需资源或步骤数  |
| 总必需单元    | `total_required_units`  | int   | `1-100`                  | 本场景必须完成的加载步骤    |
| 加载进度     | `scene_load_progress`   | float | `0.0-1.0`                | 供 UI / QA 使用的进度 |


**Output Range:** `0.0` 到 `1.0`。  
**Example:** 4 个必需步骤完成 3 个，进度为 `0.75`。

### Is Scene Event Current

The `is_scene_event_current` formula is defined as:

`is_scene_event_current = event_scene_context_id == active_scene_context_id && event_scene_version == active_scene_version`

**Variables:**


| Variable | Symbol                    | Type       | Range    | Description   |
| -------- | ------------------------- | ---------- | -------- | ------------- |
| 事件上下文 ID | `event_scene_context_id`  | string/int | valid id | 事件携带的上下文      |
| 当前上下文 ID | `active_scene_context_id` | string/int | valid id | 当前 active 上下文 |
| 事件版本     | `event_scene_version`     | int        | `>= 0`   | 事件产生时版本       |
| 当前版本     | `active_scene_version`    | int        | `>= 0`   | 当前上下文版本       |


**Output Range:** `true / false`。  
**Example:** 旧战斗场景的弹反迟到事件版本不匹配，返回 `false` 并被拒绝。

## Edge Cases

- **If 加载失败**: 进入 `Failed`，禁止半初始化场景接收输入；若 `allowRetry=true` 可重试，否则回到安全场景。
- **If 场景切换期间玩家触摸屏幕**: 输入系统处于 `Suspended`，不产生战斗输入。
- **If 旧场景事件在新场景激活后到达**: 通过 `is_scene_event_current=false` 拒绝并记录迟到事件。
- **If 战斗失败后重试**: 清理旧战斗上下文并用同一遭遇 payload 创建新 `Battle` / `BossBattle` 上下文。
- **If Boss 战失败**: 从 Boss 战入口重试，不重载整层探索。
- **If 场景卸载时仍有 VFX/SFX 或 hit stop**: 战斗反馈系统和音频管理必须收到 `SceneContextUnloading` 并清理。
- **If 角色实例创建失败**: 目标场景不得进入 `Active`；加载流程进入 `Failed`。
- **If 快速连续请求两个场景切换**: 后一个请求排队或拒绝；MVP 默认拒绝并记录 `SceneTransitionAlreadyInProgress`。
- **If 平台后台切前台**: 场景进入 `Suspending`；恢复后回到原 active scene，不补发暂停期间输入。
- **If Loading 太快无法显示进度**: 仍输出 `0` 和 `1` 两个进度事件，供测试验证。

## Tuning Knobs


| Parameter                        | Current Value | Safe Range   | Effect of Increase | Effect of Decrease |
| -------------------------------- | ------------- | ------------ | ------------------ | ------------------ |
| `min_loading_screen_ms`          | `300`         | `0-1000`     | 切换更稳定、可读           | 更快但可能闪屏            |
| `scene_transition_timeout_ms`    | `10000`       | `3000-30000` | 低端设备更少误判失败         | 卡死更晚暴露             |
| `retry_delay_ms`                 | `500`         | `0-2000`     | 失败重试更有节奏           | 重试更快               |
| `max_queued_transition_requests` | `1`           | `0-3`        | 容忍连续请求             | 更严格避免流程错乱          |


## Visual/Audio Requirements


| Event                 | Visual Feedback         | Audio Feedback   | Priority |
| --------------------- | ----------------------- | ---------------- | -------- |
| `SceneLoadingStarted` | Loading UI 或短淡入，MVP 可极简 | 可选低强度过渡音         | Medium   |
| `SceneActivated`      | 淡出 Loading，显示目标场景 HUD   | 切换环境音或战斗音乐       | High     |
| `SceneUnloading`      | 清理 HUD / 触区 / 战斗焦点      | 停止旧场景 loop / cue | High     |
| `SceneLoadFailed`     | 错误提示或安全回退 UI            | 低强度失败提示          | Critical |

## Acceptance Criteria

- **GIVEN** 收到有效 `LoadSceneRequest`，**WHEN** 场景管理开始切换，**THEN** 输入系统进入 `Suspended`，旧场景不再生成战斗输入。
- **GIVEN** 场景必需资源全部加载完成，**WHEN** 创建 `SceneContext`，**THEN** `sceneContextId`、`sceneType`、`inputContext` 和 `version` 均可查询。
- **GIVEN** 进入 `Battle` 场景，**WHEN** 场景激活，**THEN** 角色数据模型创建该战斗需要的角色实例集合。
- **GIVEN** 离开 `Battle` 场景，**WHEN** 进入 `Unloading`，**THEN** 回合、弹反、输入触区、战斗 UI、VFX/SFX 临时对象收到清理事件。
- **GIVEN** 旧场景事件携带旧 `sceneContextId`，**WHEN** 新场景已激活，**THEN** 该事件被拒绝，不影响当前场景。
- **GIVEN** 遭遇战失败且 `allowRetry=true`，**WHEN** 玩家选择重试，**THEN** 创建新的战斗上下文并复用该遭遇 payload。
- **GIVEN** Boss 战失败，**WHEN** 玩家选择重试，**THEN** 从 Boss 战入口重试，不重载整层探索。
- **GIVEN** 加载失败，**WHEN** 错误发生，**THEN** 场景进入 `Failed`，不允许半初始化 gameplay 输入。
- **GIVEN** 快速连续发起两个场景切换请求，**WHEN** 第一个尚未完成，**THEN** 第二个被拒绝并记录 `SceneTransitionAlreadyInProgress`。
- **GIVEN** Loading 很快完成，**WHEN** 进度事件发出，**THEN** 至少产生 `0.0` 和 `1.0` 两个进度值。
- **GIVEN** 平台后台切前台，**WHEN** 恢复到原场景，**THEN** 暂停期间输入不补发，场景上下文 ID 不变化。
