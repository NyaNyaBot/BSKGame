# Test Evidence

Store manual and platform-specific evidence here.

Recommended files:

- `wechat-touch-timestamp-YYYY-MM-DD.md`
- `webgl-feedback-performance-YYYY-MM-DD.md`
- `safe-area-hit-targets-YYYY-MM-DD.md`
- `hybridclr-smoke-YYYY-MM-DD.md`

Each evidence file should include:

- build identifier
- device / platform
- steps performed
- observed result
- screenshots, logs, or profiler captures when available
- pass/fail verdict and owner
